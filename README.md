# Photographic Media 📸

A modern and creative photography portfolio website designed to showcase photographs, visual stories, featured work and photography services.

## 🌐 Live Website

[Visit Photographic Media Website](https://photographics-media-ka0t.bolt.host)

## ✨ Features

- 📸 Photography portfolio
- 🖼️ Photo gallery
- 🎨 Modern and creative design
- 📱 Fully responsive layout
- 💻 Desktop, tablet and mobile support
- 🔍 Easy navigation
- ⭐ Featured photography work
- 📖 Visual storytelling
- 📞 Contact section

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📱 Responsive Design

The website is designed to provide a smooth experience across:

- 💻 Desktop
- 💻 Laptop
- 📱 Mobile
- 📱 Tablet

## 🎯 Project Purpose

Photographic Media was created to provide photographers and visual creators with a professional online presence where they can showcase their work and connect with potential clients.
